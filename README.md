## Medix Frontend 💊

A modern, scalable frontend for Medix, an online medicine marketplace for Customers, Sellers, and Admins.
Built with Next.js, delivering a fast, responsive and user-friendly experience powered by the Medix API.

## 🖥️ Live App

- **Frontend:** https://medix-client.vercel.app
- **Backend:** https://medix-server.vercel.app
